# LakApp V4.3 — Ground-Up Rebuild

Upload every item in this folder to the root of `Lakapp4.3`.

The actual supplied Libas National High School logo is embedded directly as a base64 JPEG inside `index.html` for the header and hero. The visual feature artwork is inline SVG. Therefore the page does not depend on external image paths for its main visuals.

The manifest uses local PNG copies generated from the same logo for install icons.
